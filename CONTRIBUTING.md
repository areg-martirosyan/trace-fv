# Contributing

Issues and pull requests that improve correctness, tests, documentation, or
portability are welcome.

Before opening a pull request:

1. keep all examples synthetic and free of credentials or private records;
2. do not add official pilot outputs unless the study-specific preregistration
   and release policy explicitly authorize them;
3. run `python -m unittest discover -s tests -v`;
4. run `python scripts/verify_release.py`;
5. explain any departure from the registered formulas or terminology.

Authorship and contributor credit follow actual scholarly and technical
contributions; no person is listed from an unverified or incomplete profile.
