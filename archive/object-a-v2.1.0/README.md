## Purpose

This package contains the public scientific Object A for TRACE-FV v2.1.0. Object A freezes the parent black-box evaluation protocol, public scoring rubrics, provenance and scope disclosures, related-work positioning, and release-integrity records.

TRACE-FV evaluates three observable properties of conversational-AI product sessions:

1. calibration of first-person self-descriptions under frame variance;
2. verification of a declared correction trigger before a scoped retraction or update;
3. endurance of a warranted correction across later turns and opposing frames.

The unit of evidence is the recorded product-session and its observable trajectory. Hidden model state, hidden routing, hidden memory, provider-internal mechanisms, and private subjective state are outside the evidential reach of this protocol unless separately operationalized and externally established.

## Registration boundary

Object A is the public parent protocol registration. It contains no official pilot outcomes and does not by itself satisfy the later study-specific preregistration gate.

Before the first official pilot datum is generated, a separate study-specific preregistration must freeze the exact pilot instantiation, including evaluated products, visible settings, product-specific claims, prompt materials, evidence-acquisition procedures, allocation schedule, rater execution materials, and analysis implementation.

Under the v2.1 reference design, the first official pilot datum is the first evidence-acquisition product output generated only after that study-specific preregistration has been accepted and timestamped.
