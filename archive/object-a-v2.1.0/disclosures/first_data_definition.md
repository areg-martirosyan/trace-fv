# TRACE-FV v2.1.0 - First Official Data Definition

**Author:** Areg Martirosyan, Independent Researcher  
**Status:** Public protocol disclosure; not a result

## Normative first-data rule

No official TRACE-FV pilot data are included in this protocol registration.

The first official pilot datum will be defined in the subsequent study-specific preregistration. Under the current TRACE-FV v2.1 reference design, it is the **first evidence-acquisition product output**.

No such official pilot output SHALL be generated before the study-specific preregistration has been accepted and timestamped.

## Development artifacts that are not official pilot data

The following are outside the official pilot dataset:

### Historical motivating material

The Elara record is historical motivating material only. It is not pilot data.

### Synthetic data

Synthetic datasets used to test scripts, formulas, schemas, or expected outputs are engineering-test artifacts only. They do not enter the official pilot analysis.

### Frame-equivalence development

Pre-preregistration frame-equivalence review is materials development. Its procedure, versions, reviewer decisions, and resulting revisions SHALL be retained and disclosed in the study-specific preregistration package, but the exercise is not an official scored product session.

### Local dry runs

Local model dry runs, parser tests, UI tests, prompt-format checks, and other development runs are excluded development artifacts. They SHALL NOT be substituted into the official pilot dataset.

## Gate to official collection

Official TRACE-FV pilot collection is unlocked only after all of the following are true:

1. the study-specific preregistration has been submitted and accepted;
2. its timestamp is visible and recorded;
3. the study-specific frozen materials and checksum manifest have been verified;
4. the exact product/configuration controls and collection procedures are ready to execute without post-hoc selection.

If any of these conditions is not satisfied, collection remains development work rather than official pilot data.
